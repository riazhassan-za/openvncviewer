## 2. Counting model and evidence rules

The six inventories are: (1) authoritative BRD promises; (2) authoritative FRD statements; (3) authoritative source requirement/AC leaves; (4) audit-report-derived regression/control leaves; (5) documented-limitation-derived verification-control leaves; and (6) test-established/promoted contracts. This origin records behavior absent from authoritative BRD/FRD/README/TODO requirements and audit-derived remediation. A counted test-established/promoted contract must cite an exact committed assertion-bearing test node or contain an explicit `Promotion decision:` recorded in this matrix with its rationale. Implementation existence or static observation alone does not create a counted contract; implementation citations may only corroborate another valid admission basis. Only authoritative requirements/ACs enter BRD, FRD, and source-AC coverage denominators. Audit-derived, limitation-derived, and test-established/promoted leaves are excluded from BRD/FRD rollups. An unparented authoritative AC remains in the source-AC denominator but contributes to no BRD rollup. A parent roll-up is **Fully automated** only when every linked leaf is Fully automated; it uses one non-full category only when every linked leaf shares that category; otherwise it is **Mixed**. Implementation Pass/Fail does not affect evidence roll-up. `CLIP-007` and `HIST-002.a` are retained as non-counted parent trace keys; only their suffixed leaves are counted. `UI-015` remains an unparented authoritative TODO acceptance/control statement because no verbatim higher-level input/session BRD promise exists.

Evidence categories: **Fully automated**, **Partially automated**, **Manual/dynamic only**, **Static review/config check**, **Blocked/platform-gated**, **Absent**. Observed results: **Pass**, **Fail**, **Skipped**, **Not run**, **Unknown**. Evidence category is independent of implementation result. Temporary probes are manual/dynamic; source/config inspection is static; unavailable platforms/live APIs are blocked. Complete proof Yes means the evidence establishes the entire leaf criterion, including a static presence/absence criterion.
